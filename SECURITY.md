# Security Policy

## Supported versions

Treelace is pre-1.0. Security fixes are applied to the latest release line.

## Reporting a vulnerability

Please report vulnerabilities privately to project maintainers. Do not open a
public GitHub issue for security vulnerabilities.

Include:

- Affected version
- Reproduction steps
- Impact assessment
- Any proposed mitigation

We will acknowledge receipt, investigate, and provide a coordinated disclosure
timeline.
